# Projeto Métodos Numéricos — 2º GQ

## Problema 2: Investigação de Degradação de Desempenho em Servidores

Repositório para o desenvolvimento do projeto prático da disciplina de Métodos Numéricos.

### Estrutura
- `data/`: Arquivos de dados brutos (`temperaturas.csv` e `incidentes.log`).
- `notebook/`: Jupyter Notebook para resolução do problema (`project.ipynb`).
- `src/metodos/`: Implementações dos métodos numéricos (`lagrange.py` e `newton.py`).

### Instalação
```bash
pip install -e .
```
